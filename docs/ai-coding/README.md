# AI 编程规范入口

本目录集中维护微信小程序项目的 AI 编程规范。当前只补充跨项目统一版本规则；后续新增小程序专项规范时，从本文件挂入口。

## 阅读顺序

1. 先读 [项目版本变更规范](VERSIONING_SPEC.md)，确认小程序上传版本、后端公共包版本和 Java 新项目基础坐标的处理规则。
2. 再读项目根目录 `README.md`、`project.config.json`、目标页面、工具方法或云函数。

## 必读结论

- 小程序没有 Gradle `group`；如果涉及后端 Java 新项目，默认使用 `group = 'com'` 和 `version = '1.0.0'`。
- 纯 README、AI 规范和说明文档改动不提升小程序上传版本。
- 修改运行时代码、配置、接口地址、请求头、云函数或上传包行为时，按 `VERSIONING_SPEC.md` 的补丁递增规则处理版本。
